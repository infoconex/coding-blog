I have had a Windows Phone since pretty early on, and I have to say I really like it.

At this point I am probably about as committed to the Microsoft ecosystem as I can get. When my daughter started asking for an iPod, I bought her a Zune instead.

The interface on Windows Phone is different from iPhone and Android, and that is actually one of the things I like about it. The live tiles are useful, the phone feels fast, and the overall experience is clean and simple.

Microsoft announced Windows Phone 8.1 today at Build, and there are some changes I am looking forward to.

Cortana is probably the feature getting the most attention. Microsoft is positioning it as a personal digital assistant, and I am curious to see how useful it actually is in day-to-day use.

The new Action Center is also something Windows Phone has needed for a while. Being able to see notifications in one place is a pretty basic feature at this point, so I am glad to see it finally arrive.

There are a number of other improvements, but what I like most is that Microsoft still seems committed to making Windows Phone better.

The biggest problem is still apps. iPhone and Android have a big lead there, and Microsoft has a lot of catching up to do.

But as someone who actually uses Windows Phone every day, I like the direction they are going.
